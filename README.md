# Moreeee_Image_Processing-
 A collection of three image processing projects: Blood Cell Detection for medical diagnostics, MNIST digit recognition as a computer vision benchmark, and Retinal Blood Vessel Segmentation for ophthalmology research. Each project demonstrates robust preprocessing, augmentation, and deep learning workflows.
1. Blood Cell Detection
Description:  
This project focuses on automated detection and classification of blood cells using image processing and machine learning techniques. The pipeline includes preprocessing, augmentation, and model training to identify different cell types with high accuracy. It is designed to support medical diagnostics and research by providing a scalable and reproducible workflow.

2. Numbers (MNIST)
Description:  
An implementation of handwritten digit recognition using the MNIST dataset. The project demonstrates image preprocessing, feature extraction, and deep learning models for accurate digit classification. It serves as a foundational benchmark in computer vision and showcases practical applications of convolutional neural networks (CNNs).

3. Retinal Blood Vessel Segmentation
Description:  
This project addresses the segmentation of retinal blood vessels from medical images. It leverages advanced image processing and deep learning architectures to extract fine vascular structures, supporting early detection of eye diseases such as diabetic retinopathy. The workflow emphasizes robust preprocessing, augmentation, and evaluation metrics like Dice coefficient and IoU.
